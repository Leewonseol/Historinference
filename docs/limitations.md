# 한계와 차단 사항

## 1. 원문 미확보 — 가장 큰 한계

- 레지스터의 공식 출처 22건 중 **원문이 로컬에 보관된 것은 0건**이다(`offline_text_status=UNAVAILABLE_SOURCE_TEXT`, `retrieval_status=NOT_RETRIEVED`). 이는 자료가 없다는 뜻이 아니라 이 작업에서 확보하지 못했다는 뜻이다.
- 오프라인 규칙(CLAUDE.md, 2026-10-16)에 따라 외부 사이트 접속·검색·원격 복제를 하지 않았다. 세션 초기, 규칙이 공지되기 전에 공식 사이트 접속(프록시가 거부)과 웹 검색을 시도한 적이 있으나 **그 결과는 데이터·보고서 어디에도 쓰지 않았고**, 당시 임시로 복제한 참조 저장소도 삭제했다. 분석은 `research/` 안의 파일만 사용한다.
- 따라서 모든 근거는 **의역·요약·선행 코딩**이다. 등급 A(원문 직접 인용) span은 0건이다. 몇몇 한자 단편(예: `三載之間 四行按査`, `自刺`, `瘐死`)은 로컬 노트에 적혀 있던 것을 옮긴 것으로 `PROVIDED_IN_LOCAL_NOTE_NOT_VERIFIED` 상태다.
- 원문 진술은 그 진술이 기록됐다는 관측일 뿐이며, 의역 과정에서 의미가 바뀌지 않았는지 원문 대조로 재검증하지 못했다.

## 3. 명령과 집행

`decisions.csv`의 모든 처분은 **명령(ORDER)** 이다. 실제 집행이 확인된 처분은 없다(`NOT_RETRIEVED`). 후속 기록이 명령의 이행을 뒷받침하는 경우(안핵 임명 → 복명)만 `RECORDED_FOLLOWUP`, 번복된 명령(이형원 파직 → 유임)은 `SUPERSEDED`로 둔다.

## 4. 규범·제도 제약의 범위

- 대전통편(1786-01-01 시행)과 1792 증수무원록 개정 지침만 HARD 단절점으로 쓴다. 증수무원록의 정확한 반포·시행 월일은 저장소에 없다.
- GuSoon 제도 피처(02)는 1776~1793 범위에서 검증된 맥락이며, 일부 출처는 승인 원문 도메인 밖(encykorea·moleg)이다. 1794~1795 YE 사건에 쓰면 경고(WARN)로 표시한다. 이동 가능 시간·관할 거리·연령 범위는 근거 자료가 없어 **검증하지 못했다**(이동 시간 제약은 구현하지 않음).

## 5. 가능세계와 합성의 성격

- 가능세계 후보(`models/worlds/`)는 분석층이며 최종 창작 스토리가 아니다. 축과 제약은 사람이 정의한 것이고, 확률은 식별 불가하므로 전부 `UNSCORED`다.
- 합성 비교(`models/synthesis/`)의 목표 수준·심각도·gate·가중치는 **설계 기준**이며 연구 결과가 아니다. 4건으로 학습한 모델도, 빈도 추정도 없다.
- 형태 상자 51행과 CSP 규칙 20개는 현재 코딩에서 추출한 것으로, 원문이 확보되면 행의 등급·존재가 바뀔 수 있다. 민감도 분석(증거 등급 B/C/D × gate 변형 4종)이 이 의존성을 보여 준다.
- B 설계의 출처 배정은 '교차 사건 연결 → 2차 종합 요소 수' 순으로 최소화하는 DP로 정한다. 시대 위험은 배정 후 계산하므로, 다른 출처 배정에서 시대 위험이 더 낮은 대안이 있을 수 있다.
- 오컴 필터는 요소를 빼도 목표 수준과 CSP가 그대로인 설계를 제외한다(축소판에 엄격히 지배되므로 Pareto 결과는 바뀌지 않음).
- 실존 인물에게 창작된 공모·범행을 귀속하지 않는다. A 전략의 이식은 '역사 덧씌우기'(심각도 3)와 '실존인물 귀속 위험'으로 비용화했을 뿐, 그런 서사를 사실로 제시하지 않는다.

## 6. 실행 환경

- 테스트는 Python 3 / pytest, 보조 SQL 검사는 DuckDB(설치된 경우)로 **로컬 실행**한 결과다. Oracle에서 실행하지 않았다.
- Parquet 파일은 DuckDB가 설치된 경우에만 생성된다.
