# Historinference

**네 조선 형사사건의 사료 대조와 합성사건 설계 연구** — 최아지·이차망, 조재항, 이여절·조진택, 구순–김명신

## 현재 상태

- [사료 출처 레지스터 (28개 링크·검증 항목)](research/source_register.csv)
- [사건별 조사 브리프 및 미확정 사안](research/research_brief.md)
- [Claude Code 실행 명세](CLAUDE.md)

**현재 공개된 자료는 수집 위치와 선행 검증 내용을 정리한 기초 코퍼스이며, 28개 원문을 모두 내려받아 전수 확인한 완성 코퍼스가 아닙니다.** 원문 직접 대조·문장 단위 재코딩, 사건 합성 알고리즘, 가능세계 계산은 다음 구현 단계입니다.

## 역할 분리

- **자료 조사:** 출처 위치, 검증 상태, 사료 간 충돌, 사건별 사실과 주장 구분
- **Claude Code:** `CLAUDE.md` 순서에 따라 원문 확인 → 원자 명제·인물·절차 코딩 → 기계검증 → 메커니즘 비교 → CSP·가능세계 합성 → anchor/synthetic 전략 비교 및 보고서/대시보드 개발

## 목표함수
가해자 규명·책임, 무고한 사람의 보호, 최초 판단의 오류·은폐 검증, 독립적 재검증, 유족의 이의제기 보장을 서사 목표로 둡니다. 기획의도는 통계학적 종속변수가 아니며, 4건으로 학습한 모델이라고 주장하지 않습니다. `CLAUDE.md`에 형태분석 및 제약충족(CSP)과 출처 충실성 조건을 정의했습니다.

## 사용

1. Claude Code에서 이 저장소를 열고 `CLAUDE.md`를 읽도록 합니다.
2. `research/source_register.csv`와 `research/research_brief.md`에서 출처를 추적합니다.
3. 원문 회수율과 검증 한계를 기록하며 단계별 데이터 모델과 테스트를 구현합니다.
4. 원천 저장소는 읽기 전용으로 이용합니다: [GuSoon-Inference](https://github.com/Leewonseol/GuSoon-Inference), [Chamang-Inference](https://github.com/Leewonseol/Chamang-Inference).

모든 합성 결과는 **가상 사건**으로 표시해야 하며, 실존 인물에 창작된 공모나 범행을 역사적 사실로 귀속해서는 안 됩니다.
