# 가능세계 후보와 제약 (4단계)

> 자동 생성 문서(`python -m historinference report`). 모든 수치는 `data/normalized`·`models`·`data/audit`에서 재계산된다. 원문 미보관(UNAVAILABLE_SOURCE_TEXT) 상태에서 로컬 요약·선행 코딩만으로 작성되었으며, 확률·빈도 추정은 하지 않는다.

관측된 행정행위(OBSERVED_ACT 사건·명령)는 모든 세계에서 고정한다. 실제 범행·누명 생성·증거 신빙성·공모 여부만 잠재 축으로 분기하며, 축 사이 논리 제약(`models/worlds/world_constraints.csv`)을 위반하는 조합은 제거한다. **세계 후보는 분석층이며 최종 창작 스토리가 아니다.** 확률은 자료로 식별되지 않으므로 모든 세계의 `posterior`·`likelihood`는 `UNSCORED`.
